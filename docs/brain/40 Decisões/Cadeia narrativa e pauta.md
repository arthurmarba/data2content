# A cadeia é asset → território → narrativa → pauta

O gabarito das camadas do mapa. Não é vocabulário: é regra de construção, e o código a respeita.

| Camada | O que é | O que **não** é |
| --- | --- | --- |
| **Asset** | Elemento de vida (a filha, a cozinha, o cachorro) | Credencial, diploma, habilidade |
| **Território** | Substantivo — o assunto onde se vive | Adjetivo, estilo, formato |
| **Narrativa** | Tensão ou missão — o que está em jogo | Descrição, nicho, bio |
| **Pauta** | O assunto de um vídeo | Ideia solta sem ancoragem |

## Os casos que confundem

- "Humor" **não** é território. "Humor de casal" **é** — tem assunto embaixo.
- Um prêmio **não** é asset. A sala onde ele está pendurado, talvez.
- "Falo sobre maternidade" **não** é narrativa. "Sustento a casa e não quero perder a infância dela" é.

## Por que isso vira código

Cada camada só existe se a de baixo existir. É o que autoriza o portão em [[Pauta exige narrativa]] e o que permite ao relatório semanal agrupar sem inventar ([[O mapa é o dicionário]]).
